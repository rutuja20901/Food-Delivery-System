1. User Registration Flow
Flow
Client (Postman)
        |
        v
User Service
        |
        v
Save User in DB
        |
        v
Publish NotificationEvent to Kafka
        |
        v
notification-topic
        |
        v
Notification Service Consumer
        |
        v
Save Notification in DB
What happens?
User registers.
User data saved in User Service database.
Kafka Producer sends NotificationEvent.
Kafka Topic receives event.
Notification Service consumes event.
Notification stored in notification table.

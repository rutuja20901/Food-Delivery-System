# Food Delivery Microservices Project

A Food Delivery backend system built using Spring Boot Microservices Architecture.

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL
- Lombok
- Kafka (Upcoming)
- API Gateway (Upcoming)
- HikariCP
- LogBack

## Completed Features

### User Service
- User Registration
- Login Authentication
- Password Encryption (BCrypt)
- JWT Token Generation
- JWT Validation Filter
- Role Based Access Control (RBAC)

### Roles
- CUSTOMER
- RESTAURANT_OWNER
- ADMIN

## Planned Services
- Restaurant Service
- Order Service
- API Gateway
- Notification Service (Kafka)
- Delivery Service
